# ChordWiki Bar Formatter Web

Python版「ChordWiki Bar Formatter v45」を、HTML・CSS・JavaScriptのみで段階的に移植するWeb版です。

## 現在の段階

- Web画面とレスポンシブレイアウト
- Python版と同じ6つの初期設定
- 設定値の検証とブラウザ内保存
- ブラウザ／OSのライト・ダーク設定への自動追従
- 入力と設定変更のリアルタイム反映
- 入力行と位置を揃えた行修正欄
- 各欄に独立した行番号
- 左列は行修正と空白、右列は変換前と変換後に固定
- 上段左を空白にし、下段左へ行修正を配置
- 行ラベルを省き、拍コードだけを行修正欄へ表示
- 左列幅をドラッグ変更し、上下の列幅を同期
- 左上へ縦5項目の初期設定を配置
- 初期設定と変換前の高さを同期
- 全設定の具体例を常時表示
- 初期設定の見出しを枠外へ配置
- 設定例を枠内下部へ常時表示
- 設定入力欄を72px幅へ凝縮
- 4枠の上下サイズと左右列幅の同期処理を改善
- ①初期設定・③行修正の右枠線をドラッグして列幅を変更
- ①初期設定・③行修正の右下ハンドルを上下左右へドラッグ可能
- ブラウザ標準リサイズを共有サイズ変数だけを動かす専用ハンドルへ置換
- 右列を最低180px確保し、それ以外の範囲で列幅を広く調整可能
- 右下ハンドルを枠内背景で描画し、斜線のはみ出しを防止
- スマートフォン幅でも2×2配置と全同期操作を維持
- 行修正の拍コードを変換後へリアルタイム適用
- 同一拍数も省略せず、コード数に合わせて444444のように展開表示
- 行修正の0を「ハイフンなし」として処理
- 行修正の@を`[○]`入力として処理
- Backspace/Deleteで対象を0へ戻し、英数字入力で現在位置を上書き
- コード数を超える追加入力を禁止し、選択範囲も固定長で上書き
- 貼り付け時もコード数を超えた拍コードを自動除去
- 詳細設定と使用例を変換後より下の全幅セクションへ移動
- 主操作を01変換前・02行修正・03変換後の順へ整理
- 各設定の直下に対応する使用例を配置
- 使用例をアクセント背景と左線で強調表示
- 設定一覧をカード型へ戻し、番号・短い項目名・入力欄を1行表示
- 使用例は値ごとに1行とし、折り返さず全文表示
- 720px以上のカード幅を優先し、余裕がある画面だけ2列表示
- 長い使用例はカード内横スクロールで確認可能
- 推奨拍数を全設定カードの末尾に表示
- 短端数先置き時は35を[---]と[-][----]の順で配置
- 行修正枠を青色で表示
- 全見出しを「番号. 日本語 / 英語」の1行形式へ統一
- 行修正と変換後の高さ変更を同期
- 行修正・変換前・変換後の縦スクロールを同期
- クリップボードへのコピー
- ひとことサポートを項目ごとに改行表示
- 手動ハイフン行の小節線を`[|]`へ統一し、ディレクティブ内の記号をそのまま保持
- 全テキスト枠でクリックした行番号を強調し、行修正枠だけ文字位置も強調表示
- どのテキスト枠からでも同じ行番号を全枠で連携強調
- 歌詞上のクリック位置を対応する行修正コードへ連携し、対象文字を背景色表示
- 行修正の現在行・対象コード・拍数を表示
- 行修正専用の元に戻す／やり直す操作に対応
- 行修正エラーから該当行へ直接移動
- 手動ハイフンの部分対応通知を1件にまとめ、対象行番号を一覧表示
- 手動ハイフンの対象行番号を省略せずすべて表示
- 長い手動ハイフン対象行番号をひとことサポート枠内で折り返し表示
- 変換前と変換後の文字差分から、自動追加部分を正確に強調
- 「譜面プレビューを確定」を07. 確定譜面テキストへ配置
- 移調・音名を06とキー詳細設定の両方に表示し、双方向で同期
- 重♯・異名同音設定はキー詳細設定に集約
- キー詳細設定の編集欄と仮プレビューが重ならないレスポンシブ配置
- 表示設定を初期設定と同じコントロールパネル表示へ統一
- レイアウトと表示の初期化前に確認を表示
- 初回表示は01を開き、03を閉じた状態に設定
- 04. 行修正と05. 変換後の入力枠上端を常時整列
- 03. 初期設定の全高に列幅調整ハンドルを表示
- Python版とWeb版で同じJSONケースを使うv45回帰テスト

コード記号の解析、ディレクティブ保持、ラベル処理、コードのみの行と基本的な歌詞行の整形を移植済みです。手動ハイフン行、キー推定、行修正値の適用などは、Python版との完全一致テストを整備しながら段階的に移植します。

## 起動方法

`index.html` をブラウザで開きます。サーバーやPython環境は不要です。

## 回帰テスト

隣のPythonプロジェクトにある `..\ChordWiki_Bar_Formatter\run_v45_regression_tests.cmd` を実行すると、Python版の既存セルフテスト、Python/Web共通ケース、Web各機能のテストをまとめて確認できます。共通ケースは `tests/fixtures/v45-regressions.json` に追加してください。

## データの扱い

入力したコード譜を外部へ送信しません。`localStorage` には6つの設定値だけを保存し、コード譜本文は保存しません。
