# READMEキャプチャ用テストサンプル

管理番号：`PUBLIC-002`

README画像を撮り直すときは、アプリの「入力サンプル」を押して次の状態を使用します。

## 変換前

```text
{title:変換テスト用サンプル}
{subtitle:これは実在する楽曲ではありません}
{comment:コード・小節線・行修正・譜面プレビューの確認用です}
{key:C}
[C]コード譜を[G]貼り付けると　[Am]小節線と[F]長さを自動で補います
[Dm]曲に合わない[G]部分は　[C]行修正で[Am]整えられます
[F]アクセントや[G]細かな長さも　[Em]記号で[Am]指定できます

[F]変換結果を[G]確認して　[Csus4]譜面プレビューへ[C]
```

## 行修正

```text




4444
43^4a
44^*4a

4433
```

## キャプチャ対象

1. `02. 変換前`と`05. 変換後`
2. `04. 行修正`と`05. 変換後`
3. `06. 譜面プレビュー`と左側の案内パネル

個人情報や実在曲の歌詞を使用せず、ライトテーマ、メイリオ、14pxで撮影します。
