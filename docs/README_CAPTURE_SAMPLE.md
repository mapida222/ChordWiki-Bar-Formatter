## 初期設定・表示設定

- 1小節の合計ハイフン数：8
- コード直後のハイフン数：4
- ハイフンを空白で区切る間隔：4
- 端数の歌詞前置き：する
- 直前コードの引継ぎ：しない
- 歌詞行のハイフン：指定数だけ省略
- 省略するハイフン数：4,8
- 初期設定値を使う：オフ
- 小節線`[|]`にカッコをつけない：オフ
