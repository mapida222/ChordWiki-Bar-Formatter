# 「？」補足説明 文案

管理番号：`HELP-001`

確認済みの文案です。アプリ画面へ反映します。

## 共通の表示方法（案）

- パソコン：カーソルを合わせるかクリックすると表示
- スマートフォン：タップすると表示
- キーボード：Tabで選び、EnterまたはSpaceで表示
- 画面外の場所、もう一度「？」、またはEscで閉じる
- 長い説明は入れず、詳しい操作は既存の「ヘルプ・使い方」へ案内する

## 1. 初期設定

配置候補：「03. 初期設定・使用例」の見出し右側

表示文案：

> 曲の拍子に合わせて、自動で補うハイフン数と1小節分の長さを設定します。

## 2. 歌詞行ハイフンの省略

配置候補：「歌詞行のハイフン」ラベル右側

表示文案：

> 歌詞行に付いたハイフンの表示方法を選びます。「指定数だけ省略」は対象にした長さだけ、「できるだけ省略」はコードチェンジの位置が必要な箇所を残して省略します。「すべて省略」はタイミング情報も含めて省略します。

## 3. 行修正

配置候補：「04. 行修正」の見出し右側

表示文案：

> 1行のコード順に対応する数字や記号を上書きして、音の長さや小節位置を調整します。入力例と記号の意味は、下の「行修正で使える記号」で確認できます。

## 4. 譜面プレビュー

配置候補：「06. 譜面プレビュー」の見出し右側

表示文案：

> 変換結果を譜面に近い形で確認します。移調、音名表記、小節線の表示を変更しても、変換前の原文は書き換わりません。

## 選択肢の表示順

1. 省略しない
2. 指定数だけ省略（カスタム・おすすめ）
3. できるだけ省略
4. すべて省略
