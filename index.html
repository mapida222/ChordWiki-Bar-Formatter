行修正で使える記号 / ROW EDIT SYMBOLS

          
        

        

          

            

              

                0～9ハイフン数▼
                
意味コード直後に入れるハイフンの数です。値は左のコードから順に対応し、不足した右端は自動値を使います。1文字だけでも全コードへ繰り返しません。
入力⇒結果①4⇒[----]
入力⇒結果②4444⇒[C][----][G][----][Am][----][F][----]

              

              

                a～i10以上のハイフン数▼
                
文字列説明：
意味1文字で10個以上のハイフン数を指定します。
入力→結果a→[----------]
対応a=10、b=11、c=12、d=13、e=14、f=15、g=16、h=24、i=32

              

              

                *=：ハイフンの半分音価▼
                
文字列説明：
意味=はハイフン1個の半分の音価です。
入力→結果*4→[====]

              

              

                ^>：アクセント▼
                
文字列説明：
意味ハイフン表記の先頭へアクセントを付けます。
入力→結果①^4→[>---]
入力→結果②^^4→[>>--]
組合せ^*4→[≧===]

              

              

                @○：白玉▼
                
文字列説明：
意味対象コードへ白玉[○]を付けます。白玉だけの@では次の位置までの長さが決められないため、後ろへ長さを続けて指定できます。
入力→結果①@→[○]
入力→結果②@0→[|][○]（白玉だけで長さを決めないときは、小節線で区切る）
入力→結果③@4→[○][----]（白玉の後を4個分進める）
解除選択中の文字をBackspaceかDeleteで削除します。値が不足した右端は自動値になります。

              

              

                s-：ハイフンシンコペーション▼
                
意味次のコードをハイフン1個分早く鳴らします。小節線の位置は動かしません。行頭にも入力できます。
結果-|----
入力→結果4s4→[C][---][G][-][----]
削除4s4の右の拍でBackspaceかDeleteを押すとsだけ消えて44になります。左の拍なら数字だけを削除してs4を残します。

              

              

                *s=：イコールシンコペーション▼
                
意味次のコードを=1個分早く鳴らします。小節線の位置は動かしません。行頭にも入力できます。
結果=|----
入力→結果*s44*s44→[A]=|----[Bm7]---=[C#m7]=|----[D]----|

              

              

                /アウフタクト・小節またぎ▼
                
文字列説明：
意味アウフタクト部分の指定の後ろへ/を置き、そこから通常小節へ切り替えます。アウフタクト内にコードが複数ある場合は、コードごとの指定を続けて書きます。
入力→結果22/44→[C][--][G/B][--][|][A][----][Bm][----][|]

              

              

                |小節頭を指定▼
                
意味|の位置へ優先的に小節線を加え、直後のコードを小節頭にします。
入力→結果22|44→[G][--][G#dim][--][|][C][----][G/B][----][|]

              

              

                x小節線消去▼
                
意味対象コードの前または後ろにある小節線[|]を消します。
入力→結果42x→[|][G][----][C][--]
補足この指定では、「1小節＝ハイフン8個」の区切りより小節線消去を優先します。

ABOUT
1. このツールについて

          

            

              
演奏しやすい小節表記のコード譜制作を助けるツールです

              
ChordWikiで使われるChordPro形式のコード譜に、小節線やリズム記号を追加し、演奏しやすく整えるブラウザツールです。

              
変換前の原文：[C]あいう[Am]えお譜面ではこう見えます：C　　 Amあいう　えおこの入力が、下のように変わります。

              

                
小節線とハイフンを自動追加
C　　 Amあいう　えお➜| C ----　Am ---- |あいうえお
[C]あいう[Am]えお自動[|][C][----]あいう[Am][----]えお[|]

                
コードの長さを簡単修正
C ----　Am ----あいう　　 えお➜| C ----　--　Am -- |あい　うえお
62[|][C][----]あい[--]う[Am][--]えお[|]
C ----　Am ----あいう　　 えお➜| C ====　Am ==== |あいうえお
*16分音符[|][C][====]あいう[Am][====]えお[|]

                
リズム記号を簡単追加

                  
C　　 Amあいう　えお➜| C >---　Am ---- |あいうえお
^アクセント[|][C][>---]あいう[Am][----]えお[|]

                  
C　　 Amあいう　えお➜| C ○ ----　Am ---- |あいうえお
@白玉[|][C][○][----]あいう[Am][----]えお[|]

                  
C　　 Amあいう　えお➜| C ---　Am - ---- |あいうえ　お
sシンコペーション(-)[|][C][---]あいう[Am][-]え[----]お[|]

                  
C　　 Amあいう　えお➜| C ---=　Am = ---- |あいうえ　お
*sシンコペーション(=)[|][C][---=]あいう[Am][=]え[----]お[|]

                

                
譜面を移調

          HOW TO ADJUST4. 詳しい修正方法基本操作に慣れたら見てみる
          

            

              
1
初期設定でハイフン数を変える
対象枠：02. 初期設定、04. 変換後

              
曲の拍子に合わせて設定値を変えると、自動追加されるハイフン数が変わります。

              
C　　 Amあいう　えお➜| C ----　Am ---- |あいうえお
[C]あいう[Am]えお自動[|][C][----]あいう[Am][----]えお[|]

              
4/4拍子：合計8、コード直後4 ／ 6/8拍子：合計6、コード直後3

            

            

              
2
数字でハイフン数を変える
対象枠：03. 行修正、04. 変換後

              
コード順に数字を入力して、行ごとのハイフン数を修正します。

              
C ----　G ----　Am ----あいう　えお　かき➜| C --　G --　Am ---- |あい　う　えお　かき
224[|][C][--][G][--][Am][----][|]

            

            

              
3
シンコペーションを設定する
対象枠：03. 行修正、04. 変換後

              
ハイフン食いはs、イコール食いは*sを、食い込む位置へ入力します。

              
C　　 Amあいう　えお➜| C ---　Am - ---- |あいうえ　お

アウフタクトは、短い冒頭部分の指定の後ろへ / を入力し、そこから通常小節へ切り替えます。

          LIMITATIONS5. このツールが苦手なこと気になったときに見てみる
          

            
このツールは、コード譜へ小節線やリズム記号を追加して整えるツールです。次の機能はありません。

            
    
              
  • コードを入力する機能：コード入力を省力化したい場合は、ChordWiki 用コード譜エディター（ぐらふぃーむ様）がおすすめです。
    • 
              
  • コードを歌詞の文字間へ入力する機能：りりか（fluno様）がおすすめです。
    • 
              
  • 一部の特殊・複雑なリズム表記：[>-->]など、対応していない表記があります。
    • 
            

            
※ 自動変換だけで完成するものではありません。音源を聞きながら手動で修正してください。

          

        


        

          
FAQ
6. よくある質問

          

            

              
スマホでも使えますか？

              
スマホでの利用は推奨していません。スマホでの動作確認は十分に行っておらず、細かい修正や複数の欄を見比べる操作にも向きません。PCでの利用を推奨します。アプリのインストールは不要です。

            

            

              
入力したコード譜は送信されますか？

              
いいえ。入力内容はブラウザ内で処理し、運営者のサーバーへ送信・保存しません。利用状況の計測と広告配信にはGoogle AnalyticsとGoogle AdSenseを使用します。詳しくはプライバシーポリシーをご確認ください。

            

            

              
挙動がおかしくなりました。

              
不具合や意図しない動作があれば、報告・要望フォームからお知らせください。可能であれば、操作手順や入力例も添えてください。
