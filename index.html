入力できる文字列 / INPUT GUIDE

        

        

          
読み方：すべて「入力→何をする→結果」の順です。

          
入力できる文字：数字0～9、長さa～i、記号^・*・@・x・s、行修正しないnです。

          
数字・英字は現在の長さ指定を上書きします。行末で入力しても指定数は増えません。新しいコード分を増やすときだけ、＋ 末尾に追加を押します。

          
長さ1個が、コード1個に対応します。例：4444は4コード分です。


          
基本の長さ：4→ハイフンを4個付ける→[----]

          
0＝ハイフンなし、1–9＝その個数、10以上は次の文字で入力します。

          
a=10、b=11、c=12、d=13、e=14、f=15、g=16、h=24、i=32


          
シンコペーション：4s4→後ろのコードを半音価分だけ前へ移す→[C]---=[G]=

          
sは2つの長さの間に置き、コード数には数えません。例：4s44s4は4コード分です。

          
行にsだけを書くと、その行のコードを2個ずつ組にして、すべてシンコペーションにします。

          
1小節合計4：|[C]---=[G]=|----|　1小節合計8：|[C]---=[G]= ----|


          
行修正しない：n→この行を変更しない→行修正を触る前の結果を使う


          
倍の細かさ：*4→長さ4を=で表示する→[====]

          
アクセント：^4→長さ4の先頭をアクセントにする→[>---]

          
^^4→アクセントを2個付ける→[>>--]

          
アクセント＋倍の細かさ：^*4→両方を付ける→[≧===]


          
白丸：@→白丸を付ける→[○]

          
@4→白丸の後ろに長さ4を付ける→[○][----]


          
小節線を消す：x4→そのコードの前を消す　4x→そのコードの後ろを消す

          
44x4→3番目のコード前にある[|]を消します。


          
ここで指定するのは拍数ではなく、記号の長さです。-：8分音符の4/4拍子では、2＝1拍、4＝2拍、8＝1小節です。

OVERVIEW

            
コード譜を貼り付け、整形し、完成版をコピーするツールです

            
基本の流れは、02. 変換前へコード譜を貼り付け、04. 行修正でハイフン換算の長さを整え、06. 譜面プレビューで見た目を確認し、07. 確定譜面テキストからコピーする順です。入力内容はブラウザ内だけで処理されます。

          

          
最初は初期値のままで使えます。01と03は必要なときだけ変更してください。入力や設定を変えると、変換結果は自動更新されます。

        


        

          

            
            
工程何をするところ？何をすればいい？詳細説明・例

            
              

                01DISPLAY表示設定任意
                テーマ、文字の種類・大きさ、色付け、スクロール同期を見やすく整える場所です。変換内容には影響しません。
                設定を開く ▼を押し、必要な項目だけ変更します。迷った場合は初期値のままで構いません。
                
テーマ：ダーク文字：16px戻す場合は「レイアウトと表示を初期化」

              

              

                02SOURCE変換前最初に操作
                ChordPro形式のコード譜を入力する場所です。貼り付けると、小節線と拍記号を付けた結果が自動で作られます。
                を押すか直接貼り付けます。角括弧がない場合はコードに[]を追加を押します。
                
C　D/F#　C on G↓ コードに[]を追加[C]　[D/F#]　[C on G]試す場合は「入力サンプル」を利用できます。

              

              

                03SETTINGS初期設定・使用例任意
                拍子やコード数に応じた、変換時の標準値を決める場所です。4/4拍子、6/8拍子、カスタムを選べます。
                設定を開く ▼を押して拍子を選び、結果に違和感がある項目だけ調整します。
                
4/4拍子 → 4, 8, 16, 24, 32使用例を表示 ▶で結果を確認できます。

              

              

                04ROW EDIT行修正結果を調整
                05と同じ行番号にあるハイフン換算の長さや記号を、コードごとに修正する場所です。入力値は変換結果へすぐ反映されます。
                ← →でコード間、↑ ↓で行間を移動して値を入力します。↶ 戻す↷ 進むも使えます。
                
4 → [----]4s4 → シンコペーションn → その行は修正しない^4 → [>---]*4 → [====]x4 → コード前の小節線なし0-9、a-i、s、n、^、*、@、xを使用できます。

              

              

                05RESULT変換後内容を確認
                小節線と拍記号が追加された結果を確認する場所です。不要なハイフンの一括削除や直接編集もできます。
                04と見比べ、必要なら「削除ハイフン数」を指定します。途中結果を使う場合はでコピーします。
                
注意ここで直接編集した内容は、02・03・04を変更して再変換すると上書きされます。通常の修正は04で行います。

              

              

                06SCORE譜面プレビュー仕上がり確認
                完成時の譜面を確認する場所です。移調、♯・♭表記、キーごとの詳細設定、小節線表示を調整できます。
                譜面を確認し、必要なら移調 ▼ ▲やキー詳細設定…を操作します。
                
移調：+2音名：♭表記広く確認する場合は「別画面で開く」

              

              

                07COMMITTED確定譜面テキストラスト
                06で確認した譜面を確定し、保存・投稿に使う最終テキストを取り出す場所です。
                譜面プレビューを確定を押し、開く ▼で確認してからを押します。
                
完了コピーしたテキストをChordWikiなどへ貼り付けます。「履歴に追加」は05の変換後表示を保存し、履歴から02の変換前へ採用できます。
